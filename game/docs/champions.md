# Champions

Les valeurs `a/b/c` sont celles des rangs 1★/2★/3★. ✦ : valeur multipliée par la Puissance (100 = base).
PV et PA augmentent avec le rang (×1 / ×1.8 / ×3.24 pour les PV, ×1 / ×1.5 / ×2.25 pour les PA).
